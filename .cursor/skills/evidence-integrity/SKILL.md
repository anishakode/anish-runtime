# Evidence Integrity

## Authority

```text
Canonical repo Evidence Graph  →  build projection  →  /evidence.json
```

Repository data is authoritative. `/evidence.json` is derived public projection only.

## States (never silently upgrade)

- `PUBLIC_CODE_VERIFIED`
- `PUBLIC_DOCUMENT_VERIFIED`
- `OWNER_CONFIRMED_PROFESSIONAL`
- `RESUME_DOCUMENTED`
- `PRIOR_PROJECT_CONTEXT`
- `PORTFOLIO_EXTENSION`
- `LIMITED_EVIDENCE`
- `NOT_DEMONSTRATED`

Semantic similarity = relevance, **not** proof.

## Source Trace

Claims should resolve to type, repo, path, immutable commit SHA when GitHub-backed.  
Evidence panel is the feature; SVG connectors are enhancement only.

## Search order

Exact → alias → prefix → keyword → typo → semantic fallback (only if needed).

## Signal / Composer

- Allowlisted read-only tools only
- Model passes IDs + layout; software rehydrates facts
- Invalid `ui_plan` → full fallback (no partial generative UI)
- Gap notice when evidence missing — never improvise professional facts

## Fork

LLM extracts requirements only. Classify with deterministic rules.  
Semantic-only ≠ `VERIFIED`. No fit %. Gaps stay visible.

## Exclusions

Do not reintroduce obsolete identity (e.g. old emails) or conflicting profiles excluded in the handoff.

## Interview / Ending

Interview My Work: no answer key, no scores. Ending Signal: session-not-person; no raw JD/queries in architecture reveal; no fabricated journey density.

## Failure Museum

Proof outranks narrative. Empty museum is valid.
