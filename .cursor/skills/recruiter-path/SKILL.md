# Recruiter Path

## Non-negotiable

A visitor must reach conventional information **without**:

- running the experience
- using AI
- using a terminal
- finishing an animation
- interacting with a graph
- breaking a system
- entering a lab

## Permanent access

Always available: **Work · Experience · About · CV · Contact**

## First viewport must communicate

- **Anish Akode**
- **AI · ML · Software Engineering**
- Fast path to work / CV / contact

Advanced interaction is enhancement, not a gate.

## Progressive enhancement

| Level | Must remain good if higher levels fail |
|-------|------------------------------------------|
| HTML/CSS | Identity + core content understandable |
| JS | Interactions appear |
| Advanced visuals | Labs/diagrams |
| AI | Signal / adaptive composition |

## Checks before merging UI changes

- [ ] Nav still exposes utility routes
- [ ] Skip / Escape exists for cinematic sequences
- [ ] Mobile doesn’t require precision drag-only UX
- [ ] No chatbot bubble as the only way to learn who Anish is
