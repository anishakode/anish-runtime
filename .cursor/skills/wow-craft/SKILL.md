# WOW Craft

## Bar

Amaze by making **engineering evidence feel alive and inspectable**.  
If removing the effect still leaves the proof intact, the effect was decoration — cut or justify it.

## Signature WOW (V1 — execute well)

1. Portfolio builds itself (RUN ANISH)
2. Executable CV / evidence-linked skills
3. Break the System
4. Watch Anish Debug
5. AI controls interface (Signal → composed UI)
6. Consent Recompile
7. Project X-Ray
8. Challenge / boundary scenarios
9. Fork Anish
10. Failure Museum (truthful; may be empty)
11. Under the Surface
12. Ending Signal → human contact

**Execution quality > feature quantity.** Do not add Phase-2 WOW during V1 casually (print export, voice nav, Hiring Room, terminal Easter egg, heavy WebGPU — backlog only).

## Adapt inspiration (similar ≠ clone)

Take market *principles*; rebuild RUNTIME-native (see `research-first` translate table).

## Motion constitution

Nothing moves without a reason. Examples: node appears = discovery; pulse = live; disturbance = failure; reorganize = recompile; trail = exploration.  
Require calm periods. Always support reduced motion.

## Anti-gimmick checklist (before shipping UI)

- [ ] Does this let someone inspect real evidence better?
- [ ] Does it show ability rather than claim it?
- [ ] Does recruiter clarity survive?
- [ ] Could deterministic software do this better than AI?
- [ ] Does evidence exist?
- [ ] Works on mobile / without motion / if AI fails?

If unclear → do not implement; propose and wait for approval.

## Emotional journey

Recognition → Curiosity → Proof → Interaction → Tension → Intelligence → Investigation → Challenge → Relevance → Reflection → Reveal → Contact
