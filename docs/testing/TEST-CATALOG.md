## Strength rules

1. Happy-path alone is insufficient — include at least one rejection / absence / invalid-input case per contract area.
2. When adding a feature, add catalog rows + tests in the same change; refresh `TEST-STATUS.md` via `pnpm test:status`.
3. If an edge cannot be automated, list it under milestone **Known gaps** — never silent.
